# ⚡ Electricity Billing System

## 📌 About the Project
The Electricity Billing System is a beginner-friendly Python project that calculates electricity bills based on the number of units consumed by customers. It uses a slab-based pricing system to calculate the total bill amount.

## ✨ Features
- Accepts the number of customers.
- Collects customer names and electricity consumption.
- Calculates bills using different electricity tariff slabs.
- Displays customer details, units consumed, and bill amount.
- Validates negative unit values.

## 🛠️ Technologies Used
- Python 3

## ⚙️ Electricity Tariff

| Units Consumed | Rate per Unit |
|---|---:|
| First 100 units | ₹1.50 |
| Next 100 units | ₹2.50 |
| Next 300 units | ₹4.00 |
| Above 500 units | ₹6.00 |

## 🚀 How to Run
1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python app.py
   ```

6. Enter the number of customers, their names, and their electricity consumption when prompted.
